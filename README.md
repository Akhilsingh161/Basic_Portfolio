# AI/ML Student Portfolio

A personal portfolio website created using **HTML only**, without CSS or JavaScript.

## Features
- Personal introduction and career objective
- Academic records and marksheet links
- Technical skills
- Projects and areas of interest
- Contact information and message form

## Technologies Used
- HTML5

## How to Run
1. Download or clone this repository.
2. Open `index.html` in any web browser.
